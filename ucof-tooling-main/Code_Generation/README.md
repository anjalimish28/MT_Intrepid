## Requirements
* EMF Installation 
* UCoF Model imported into workspace
* Acceleo Plug-In for Eclipse Installation

## How-To
* Import ecore2(coding_language) project
* Create an Acceleo launch configuration
* Select the ecore2(coding_language) project
* Set the main class as ecore2(coding_language)
* Select ucof.ecore as the model
* Select a target folder (e.g., .../ecore2(coding_language)/(coding_language_classes))
* Run the configuration as a java application
