## Requirements
* EMF Installation 
* UCoF Model imported into workspace
* Acceleo Plug-In for Eclipse Installation

## How-To
* Import ecore2html project
* Create an Acceleo launch configuration
* Select the ecore2html project
* Set the main class as ecore2html
* Select ucof.ecore as the model
* Select a target folder (e.g., .../ecore2html/documentation)
* Run the configuration as a java application
