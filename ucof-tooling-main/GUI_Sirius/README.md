## Requirements
* EMF with UCoF
* Sirius Plug-In for EMF

## How-To
* Follow the instructions to work with UCoF from gitlab.com/ucof/ucof
* Import the sirius project into the UCoF workspace >> NOT the main EMF workspace, but the Eclipse Application workspace!
* Right-Click on the ucof instance file and select "New" and "Representation File" if not already present
* Rick-Click the "Representation File" and select "Create Representation"
* Select the "Devices Diagram" in the following selection
* Select the "Platform" element from UCoF as root model
* If a platform has already been configured, you might need to refresh the diagram to reflect the current configuration
