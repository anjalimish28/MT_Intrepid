# Tooling for UCoF 
![UCoF Logo](Media/ucof__tooling_logo_128.png)

UCoF is an open-source model for the configuration of avionic platforms developed by the Institute for Aircraft Systems Enginnering (FST) at the Hamburg University of Technology (TUHH). For more information please visit to gitlab.com/ucof/ucof

To support working with the model, this project includes different tools. The documentation for each tool is inside its folder.

## Available Tools
* Documentation_generation
  * Ecore2HTML Generation >> Generate an HTML documentation out of an ECORE model through the Acceleo Scripting Language (ucof_tooling/documentation_generation)
* Code_Generation
  * Ecore2Python Generation >> Generate Python classes for object oriented programming with UCoF through the Acceleo Scripting Language (ucof_tooling/code_generation)
  * Ecore2Matlab Generation >> Generate Matlab classes for object oriented programming with UCoF through the Acceleo Scripting Language (ucof_tooling/code_generation)
* GUI_Sirius
  * Graphical User Interface for UCoF >> Work with UCoF through a graphical user interface (ucof_tooling/gui_sirius)
* ED247_Python_Workspace
  * Export ECIC files from UCoF document >> Works with classes from Ecore2Python Generation
